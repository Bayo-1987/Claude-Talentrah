Merged by the merge captain (S2).

### What changed
`src/lib/jobs/extract-jd.ts` gained `inferJobSeniority(title)`: the same title ladder as `inferSeniority`, with no default. A title that says nothing returns `undefined`, stored as `NULL`, which the card already renders as no chip and the Seniority filter simply does not match. Before this, 412 of 662 open postings (2026-10-01) were the `"mid"` default, so "Mid-level" on a card meant "we could not tell". The Greenhouse, Lever, Workable and schema.org adapters and the employer draft and import paths use the new function; a source-level test fails if posting-side code calls the defaulting one.

Three deliberate rule changes, each pinned by real titles from the board: a bare "executive" is no longer executive-level (Executive Assistant, Finance Executive, Sales Executive; C-level and directors still are); assistant / associate / deputy manager is mid; "trainee" is entry. A bare "Manager" is deliberately left unknown (a Product or Project Manager is an individual contributor, an Engineering Manager is not, and the title cannot say which).

`inferSeniority` itself is unchanged: `src/lib/matching/score.ts` calls it on the candidate's latest title, and changing it would re-score users. It is pinned (`inferSeniority("Accountant") === "mid"`).

### Not a production write
No migration, no backfill. Every ingest run upserts `seniority` with the rest of the row, so each still-listed posting becomes `NULL` on its next refresh; closed rows keep their value and age out. `0069` invalidates a posting's `match_scores` on a JD change, so scores recompute on the same path.

### Why it was held, and why it no longer is
It was held until the scorer was proven neutral for unknown seniority. S3's A1 (#654) landed `tests/matching/scorer-seniority-unknown-neutral.test.ts` (score with `undefined` seniority equals pure skill coverage for a graduate, an accountant, a head of finance and a CFO). This PR adds the other half, `tests/jobs/seniority-pipeline-neutral.test.ts`: silent titles go through `inferJobSeniority` to `undefined` and are scored at skill coverage.
