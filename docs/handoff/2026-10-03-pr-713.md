### What changed
The ingest route now runs the gap-driven match-score refresh at its end (after both sweeps and the proactive alerts), inside a deadline measured from the route's start, skipped cleanly when ingest used the budget, and unable to throw. Its summary is a new, purely additive `postIngestRefresh` field on the route's JSON response (no user ids) and one console line. The gap-filling write is now INSERT ... ON CONFLICT DO NOTHING (`persistScoresOrRetryStale(..., "insert-missing")`), so overlapping writers cannot overwrite each other or double count; no advisory lock, because PostgREST pools connections (migration 0082) and a lease table would need a migration. The Actions workflow's `curl --max-time` goes from 60 to 330 (above `maxDuration` 300), still without retry, with an explicit error on a curl failure and one greppable summary line. No migration. See the PR body for the evidence, the regression proof and the one existing test that was adapted.
