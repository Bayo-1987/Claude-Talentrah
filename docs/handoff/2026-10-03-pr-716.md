### What changed
Adds `POST /api/admin/rescore-stale-match-scores` (admin secret; constant-time check; bare 401 with no detail): a **dry run by default**, and with `{"write": true}` a rescore of exactly the `match_scores` rows that carry no `explanation.roleFit` (computed before A2's role-family caps), for users with a base resume. Bounded (default 1,000 rows per write call, whole users only, a 200 s self-stop under `maxDuration = 300`) and resumable (`nextCursor`; a re-run processes nothing twice). Users with no base resume and rows on closed postings are skipped and counted. **Merging does not rescore anything**: the write run needs the owner's yes on the dry-run counts. No migration.
