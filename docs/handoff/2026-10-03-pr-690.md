### What changed
`npm run handoff-fill-merge-facts` fills the merge time and the merge SHA into `docs/handoff/<date>-pr-<n>.md` entries that still carry the placeholder, from the GitHub API. GET-only, dry run by default (`--write` applies), touches only the PR table row of an entry whose PR is merged, and reports anything it cannot safely fill as `NEEDS ATTENTION` instead of guessing. 25 unit tests over recorded API fixtures. No app change, no migration. `docs/handoff/TEMPLATE.md` points at it.
