### What changed
- **E2, salary currency.** The free-text box is a `<select>` of exactly NGN, USD, GBP, EUR, CAD, KES, GHS, ZAR, stored as the ISO code (`SalaryCurrencyField`). The default comes from the signed-in member's `profiles.country` (`organizations` has no country column) via `defaultSalaryCurrency`: NG/GH/KE/ZA/GB/US/CA map to their currency, the 27 EU states to EUR, anything else to NGN. The edit form shows the stored value; a stored code outside the eight shows "Select a currency" instead of silently relabelling the amount. Server gate: `readSalaryForm` moved out of the `"use server"` file into `src/lib/employer/salary-input.ts` and requires an exact member of the eight (no trim, no case folding). No amount stores no salary; an amount with no currency is an error. No migration.
- **E4, layout.** "Assessment exercise files" lives under the "Attach an assessment" checkbox and shows only while it is ticked. Unticking hides, never deletes: on Create the staging picker stays mounted but hidden (a pick survives untick and re-tick; submitting unticked discards what was staged), on Edit the saved files stay on the server until Save with the box unticked. The "Let Farah scope this job" button uses the `FarahMark` SVG, aria-hidden, no text glyph; a test forbids star and sparkle glyphs in `src/components/employer`.
- **E5, check.** The job description editor was already a textbox named "Job description" and axe-core reports no violation, so nothing was changed. An e2e pins it, with a mutation proving it would catch an unlabelled editor. `axe-core` was added as a devDependency (already in the lockfile transitively).
