### What changed
Job title, company, skill gaps and resume context now reach Farah's system prompt inside labelled `<untrusted_data>` blocks with one rule (data, never instructions); every angle-bracket form in that text is escaped, the zero-width joiners that carry meaning are kept, and meaningless invisible characters are stripped. One chip registry (`src/lib/farah/chip-registry.ts`) feeds the chip list, the per-chip instructions, the route's allow-list and the logged entry point, with a test that fails if any chip is missing from any consumer. The `farah_call` log line gains `prompt_tokens` and `completion_tokens` (numbers or null), and the same two counts are saved on the reply row's existing JSON `context` (no migration). Characterization tests pin when the charge commits (when the reply completes). No migration. Files deleted: none.
