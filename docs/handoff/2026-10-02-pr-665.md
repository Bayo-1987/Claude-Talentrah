### What shipped
`vercel.json` `ignoreCommand` runs `scripts/vercel-ignore-build.mjs`, which skips a PREVIEW build only when every file the PR changes is `docs/**`, `tests/**`, `e2e/**` or repo-root markdown; production (any `VERCEL_ENV` other than exactly `preview`) always builds; any git failure builds; the diff is the whole PR against its merge-base with main, with `--no-renames` (a rename of a `src/` file into `docs/` otherwise hides the deleted source path; caught by a real-git test that failed first). The Lighthouse workflow got the same list as `paths-ignore`, pinned equal by a test; it is the only workflow that depends on a preview.

### Verification (the four parts), and what did NOT work
1. **API**: `merged: true`, `merged_at` 2026-10-02T14:09:22Z, `merge_commit_sha` `5817444640f13612c9f368623022a98580528604`, head `1f4fea67`.
2. **Fresh shallow clone** of `main` (`5817444` in its history): the script, its type stub and both test files present; `ignoreCommand` in `vercel.json`; `paths-ignore` in the Lighthouse workflow.
3. **Live on Vercel: the Lighthouse half worked, the preview half did NOT.** #645 (docs-only, handoff-status.md) has no Lighthouse check at all: skipped, not failed or hanging. But its preview built, and the build log (deployment `dpl_H9PgCfqUbwLidGh6iMU9Zs6xUhey`, commit `05bb7c5`) says:
   `[ignore-build] BUILD: could not diff against main (Command failed: git fetch --no-tags origin +main:refs/remotes/origin/main): build`
   **Vercel's checkout is a shallow, single-branch clone with no usable `origin` remote** (it clones in about two seconds), so the script's fetch of main from `origin` failed on every build and every preview built. The fail-safe worked (it built); the feature never did. My earlier note, "Vercel clone depth unproven", named the worry but the tests only used clones that HAD an origin, which is the one thing Vercel's does not. Fixed in the follow-up PR (`ci/ignore-build-no-origin`): main is fetched by URL from Vercel's `VERCEL_GIT_REPO_OWNER`/`VERCEL_GIT_REPO_SLUG`, tested in a real shallow single-branch clone with the remote removed.
4. **Tests against merged main**: `tests/ci` on the fresh clone, 81 tests green; required checks green on the PR's head.
